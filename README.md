# AI Infrastructure Lab

Welcome!

If you've landed here after reading one of the AI Infrastructure articles, you're in the right place.

One thing I've always felt while learning is that reading about a concept is only half of the journey. You might understand what Continuous Batching, KV Cache, Kubernetes, or GPU Memory Management are, but the real understanding comes when you actually build them, change the code, and see how they behave.

That's why this repository exists.

Every time an AI Infrastructure article is published, the goal is to have a practical implementation here that you can explore on your own. Instead of just reading an explanation, you can clone the repository, run the code, make changes, break things, fix them, compare different approaches, and see the results yourself.

Don't think of these folders as finished projects or libraries. Think of them as a playground.

Try changing parameters.
Replace one implementation with another.
Measure latency.
Compare throughput.
Introduce bugs.
Experiment with different ideas.

The best way to understand AI Infrastructure is by asking "What happens if I change this?" and then actually trying it.

This repository is being built alongside the articles, so it will continue to grow over time as more topics are covered. The idea is simple: every concept should have something you can run, modify, and learn from—not just read about.

Whether you're completely new to AI Infrastructure or already working in the field, I hope these examples make the concepts a little easier to understand and encourage you to experiment on your own.
